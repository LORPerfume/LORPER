# مدينة الياسمين — دليل التعديل

لعبة عيد ميلاد ثلاثية الأبعاد بتشتغل على التلفون من المتصفح (Three.js)، بالعرض.

## الملفات

| الملف | شو فيه |
|---|---|
| `config.js` | **كل النصوص والأسماء والأسئلة والرسائل والصور والإجابات.** هون بتعدّل ٩٠٪ من الأشياء. |
| `index.html` | هيكل الصفحة والواجهات. |
| `css/game.css` | الألوان والخطوط وشكل الواجهة. |
| `js/core.js` | الحفظ، الصوت والموسيقى، نظام المهام، الحقيبة، الإنجازات. |
| `js/world.js` | المدينة والمحلات من جوّا والحديقة السرية والإضاءة (نهار/غروب/ليل). |
| `js/ui.js` | الواجهات: الحوار، الحقيبة، المهام، الخريطة، الألبوم، الإعدادات، والألعاب المصغّرة. |
| `js/game.js` | الحركة والكاميرا والشخصيات ومنطق القصة وسباق التاكسي ونجوم الليل والنهاية. |
| `assets/face.png` | صورة وجهها (بتطلع على راس الشخصية). |
| `assets/photos/` | حط هون صور الذكريات وصورة الهدية. |

> ملاحظة: الصور مرفوعة على المستودع، والمستودع عام. يعني أي حدا بيفتح المستودع بيقدر يشوفها.

**رابط اللعبة على GitHub Pages:** https://lorperfume.github.io/LORPER/ (بيحوّل على `games/birthday/` وبيتحدّث تلقائياً مع كل تعديل على `main`).

## كيف أشغّل اللعبة؟

- **الأسهل:** من رابط الـ Artifact (اللعبة منشورة هناك مع الصور).
- **على GitHub Pages أو أي سيرفر:** ارفع مجلد `games/birthday` كامل مع مجلد `assets`.
- **على جهازك:** لازم سيرفر صغير، لأن فتح الملف مباشرة (`file://`) بيمنع تحميل الصور. مثال:
  `cd games/birthday && python3 -m http.server 8000` وبعدين افتح `http://localhost:8000`.

## تغيير النصوص

افتح `config.js`. كل قسم عليه تعليق بالعربي:

- `herName` اسمها أو الدلع، و`fromName` توقيعك.
- `gameTitle` و`cityName` اسم اللعبة والمدينة.
- `streets` أسماء الشوارع، و`shops` أسماء المحلات (بتطلع على اليافطات).
- `npcs` أسماء الشخصيات وألقابها.
- `dialogs` كل حوارات الشخصيات. كل شخصية إلها حالات (مثلاً `start` و`done`)، واللعبة بتختار الحالة حسب التقدّم.
- `letters` **الرسائل السبعة.** كل رسالة بتطلع بمهمة، ولما يكتملوا بينعرضوا كخطاب واحد مع موسيقى هادية.
- `finale.message` الرسالة الأخيرة بعد فتح الهدية.

`{name}` بأي نص بتنستبدل تلقائياً باسمها.

**أي نص مكتوب جنبه "(تجريبي)" لازم تكتب مكانه كلامك إنت.** ما حطيت ذكريات حقيقية من عندي.

## الأسئلة والإجابات

- **"كم بتعرفيني؟"** ← `quiz`. لكل سؤال: `q` السؤال، `options` الخيارات، `correct` رقم الخيار الصح (**العدّ من 0**)، و`hint` التلميح اللي بيطلع لما تغلط. بتقدر تضيف أسئلة قد ما بدك. إذا غيّرت عددهم، غيّر كمان `count` بمهمة `quiz` بقائمة `quests`.
- **المقهى** ← `cafe.drinks` و`cafe.correct` و`cafe.hint`.
- **الورد** ← `flowers.bouquets` (اسم ولون) و`flowers.correct` و`flowers.hint`.
- **المطعم** ← `restaurant.question` (سؤال الذكرى)، و`restaurant.plateNote` (الورقة اللي تحت الصحن).
- **البوتيك** ← `clothes.outfits` (ألوان الفستان والجاكيت والحجاب والإكسسوار: `necklace` قلادة، `brooch` بروش، `crown` تاج) و`clothes.correct`. اللبسة الصح بتصير لبستها بالفعل.
- **لغز الساعة** ← `clock.hour` و`clock.minute` (الدقائق بخطوات من ٥) و`clock.hint`.
- **كلمة السر** ← `password.word` الكلمة، و`password.symbols` الحرف اللي بيعطيه كل مكان. لازم حروف `symbols` تكوّن الكلمة نفسها.
- **صالة الألعاب** ← `arcade.target` عدد القلوب، و`arcade.seconds` الوقت.
- **نجوم الليل** ← `stars`، و**سباق التاكسي** ← `taxi.seconds`.

## الصور

### صور الذكريات (الألبوم)
1. حط الصور بمجلد `assets/photos/`، مثلاً `assets/photos/first-date.jpg`.
2. بـ `config.js` ← `memories`، غيّر `src` لمسار الصورة:
   ```js
   { id: 'm1', spot: 'plaza', place: 'ساحة الساعة', title: 'أول طلعة', caption: 'كلامك عن الصورة', src: 'assets/photos/first-date.jpg' },
   ```
3. `spot` مكان الصورة بالمدينة. الأماكن المتاحة: `plaza`, `park`, `cafeTerrace`, `alley`, `taxiStand`, `fountain`.
4. `place` اسم المكان مثل ما بتحبوا تسمّوه (ذكرياتنا في المدينة).

الصور ما بتنكشف إلا لما تلاقيها. بعد ما تلاقيها بتطلع بالألبوم وعلى حوامل الصور بالحديقة السرية.

### صورة الهدية
حطها بـ `assets/photos/` واكتب مسارها بـ `finale.giftImage`. إذا تركته `null` بتطلع صورة تجريبية مكتوب عليها إنها تجريبية.

### صورة وجهها
بدّل `assets/face.png`. الأفضل تكون مقصوصة بيضاوية بخلفية شفافة (PNG) وقياسها حوالي 180×260.

## المهام والمكافآت

المهام بـ `config.js` ← `quests`. لكل مهمة:
- `id` معرّف فريد، و`kind` يا `main` (رئيسية) يا `side` (جانبية).
- `title` و`desc` الاسم والوصف.
- `requires` المهام اللي لازم تخلص قبل ما تنفتح هاي المهمة.
- `objectives` الأهداف. `count` إذا الهدف بيتكرر (مثل جمع ٣ أشياء).
- `rewards` الأغراض اللي بتنعطى مرة وحدة بس لما تخلص المهمة (معرّفاتها بـ `items`).

**تعديل مكافأة:** غيّر `rewards` للمهمة. لإضافة غرض جديد، ضيفه بـ `items` (اسم وأيقونة ونوع ووصف).

**تعديل شروط فتح المناطق:**
- المحلات: `SHOP_OPEN` بـ `js/game.js` (كل محل بينفتح بعد مهمة معيّنة).
- البوابة النهائية: `requires` لمهمة `finale`.
- زقاق الياسمين: بينفتح بعد مهمة `signs`.

**إضافة مهمة جديدة** بدها خطوتين:
1. بـ `config.js` ضيف المهمة لـ `quests`:
   ```js
   { id: 'bench', kind: 'side', title: 'مقعدنا', desc: 'اقعدي عالمقعد بالساحة.', requires: ['welcome'],
     objectives: [{ id: 'sit', text: 'اقعدي عالمقعد' }], rewards: ['heart1'] },
   ```
2. بـ `js/game.js` جوّا `setupActs()` ضيف التفاعل اللي بيتقدّم فيها:
   ```js
   itemAct('bench', 'plaza', () => 'اقعدي هون', () => G.Q.open('bench'), async () => {
     await say(null, ['هون كنا نقعد…']);
     G.Q.progress('bench', 'sit');
   }, '🪑');
   ```
   `'plaza'` اسم نقطة من نقاط `world.js` (أي `point(...)`).

## الحفظ

- الحفظ **تلقائي على نفس الجهاز ونفس المتصفح** (localStorage). **مش متزامن بين الأجهزة.**
- بيتحفظ: المهام، الحقيبة، الصور والرسائل المكتشفة، المناطق المفتوحة، اللبسة، الإعدادات، وقت اليوم، ومكان الشخصية.
- المكافآت ما بتتكرر، حتى لو انضغط الزر كذا مرة أو تحدّثت الصفحة.
- **لعبة جديدة:** من الإعدادات (بيطلب تأكيد قبل ما يمسح التقدم).
- إذا خلّصت اللعبة، النهاية ما بتنعاد لحالها بس تفتح الصفحة. بتقدر تعيدها من القائمة ☰ ← "إعادة النهاية".

## الإعدادات داخل اللعبة

الموسيقى، المؤثرات، تقليل الحركة والمؤثرات، والظلال. إذا التلفون بطيء، اللعبة بتطفي الظلال وبتخفف الدقة لحالها.

## التحكم

- **يسار الشاشة:** عصا تحكم للمشي.
- **يمين الشاشة:** اسحب لتلف الكاميرا.
- **زر 🏃‍♀️:** ركض.
- **الزر الوردي الكبير:** تفاعل (بيطلع لما تكون قريب من شخص أو باب أو غرض).
- على الكمبيوتر: الأسهم أو WASD للمشي، Shift للركض، E أو Enter للتفاعل، Esc للقائمة.
